# NDX 双轨策略历史回测（研究用途）

本分支只新增 **手动触发** 的研究工作流和独立脚本，不修改现有 `scripts/ndx_signal.py`、`signal.json`、Pages 或日报工作流。

## 手机 GitHub 操作

1. 合并 PR 后打开仓库 **Actions**。
2. 选择左侧 **Research NDX dual-track backtest**，点击 **Run workflow**。
3. 保持默认 `dca_rmb_per_session=300`（假设每天三只场外基金各100元，实际仅用NDX代替净值）、`core_cap_pct=20`，选 **main** 后运行。
4. 任务完成后打开该次运行页，最下方 **Artifacts** 下载 `ndx-dual-track-research`，查看 `ndx_dual_track.json`。
5. 若运行失败，先打开日志查看 FRED/Yahoo 数据源或依赖错误，不要依据旧结果买卖。

## 三组比较

- F原版：200日SMA上下1%的趋势迟滞，40日历史年化波动率，目标 `min(60%, 10%/vol)`，弱势乘0.35。
- F增强（实验假设）：原版基础上，若价格低于20日SMA或20日SMA低于50日SMA，目标乘0.5。
- 双轨（指数替代模型）：场外每天按固定人民币小额从**同一笔初始现金**定投，达到上限停止；场内执行增强版策略，场内资金占比系数为 `1 - core_cap_pct`。

所有策略以**一周最后一个XNYS交易日收盘**为信号，下一交易日的**指数收盘价**模拟执行，不是ETF盘口实际成交价。只有目标变化至少3个百分点才调整。

## 结果解释和限制

- 默认研究本金115000元，场外每日300元合计，场外上限20%，每次交易单边10bps模拟成本。
- 报告分别对比2001—2017、2018—2025以及2001—2025；各分段重置资金，参数可能受历史结果影响，因此2018—2025**不能声称是真正未碰过的样本外**。
- 本研究仅有NDX指数数据：没有人民币汇率、159632或其他场内ETF的历史溢价与价差、涨跌停/临停、申购限额、基金真实NAV、主动基金策略敞口、税费或具体申购日历。
- 场外基金**不是**NDX等价物，此处用NDX当作统一假设仅为了评估策略结构；可能严重偏离真实收益和回撤。
- 指数点位不能实际交易。回测只作为初筛，不构成当前建议仓位或交易授权。
- 不写回 `signal.json` 或每日自动日报任务，生成文件仅放在Action的Artifacts，运行前后不改变实盘状态。

## 运行前置和审查

需要完整的FRED `NASDAQ100`日收盘序列，至少覆盖1999—2025；若FRED失败，代码回退到Yahoo `^NDX`，并在结果中记录使用来源。失败则不产生有效策略结果，不可伪造数字。
